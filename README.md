# Our Capital

Небольшое приложение на Vue 3 и Vite с публикацией в GitHub Pages.

## Локальный запуск

Нужен Node.js 24 (версия указана в `.nvmrc`).

```sh
npm ci
npm run dev
```

## Сборка

```sh
npm test
npm run build
npm run preview
```

Готовый сайт находится в `dist/`. Приложение использует базовый путь `/our-capital/`,
поэтому локальная версия также открывается по этому пути.

## Страницы

Посвящение открывается по `/our-capital/#/`, а кнопка «нажми лапкой» ведёт на
`/our-capital/#/finances`. Используется Vue Router с hash history, чтобы прямые
ссылки и обновление страницы работали в GitHub Pages без настройки сервера.

В разделе финансов на компьютере используется боковая навигация, а на телефоне —
нижняя панель. Основной маршрут открывает обзор капитала, распределение активов
и список счетов. Остальные разделы:

- `#/finances/securities` — ценные бумаги;
- `#/finances/securities/iis` — ИИС, отдельная вкладка внутри ценных бумаг;
- `#/finances/crypto` — крипта;
- `#/finances/savings` — наличные и накопления.

## Счета и аналитика

Интерфейс предназначен только для просмотра. Счета задаются в
`src/data/accounts.js`: идентификатор, название, категория, текущая стоимость
и валюта. После изменения данных нужен commit и push в `main` для публикации.
Обзор складывает все счета в выбранной валюте; ценные бумаги и ИИС объединяются
в одну группу распределения без повторного учёта. Суммы RUB, BYN, USD и EUR
показываются отдельно, без пересчёта по курсу.

Все посетители видят данные из опубликованной сборки. Форм редактирования нет;
`localStorage` для счетов не используется. Пока файл данных пуст, обзор показывает
нулевую сумму и пустое распределение.

`npm test` проверяет данные из кода, агрегацию, точность сумм и разделение валют.
Эти проверки также выполняются в CI.

## GitHub Pages

Workflow `.github/workflows/deploy.yml` собирает приложение при каждом push в
`main`. Если GitHub Pages включён, workflow также публикует сайт. Пока Pages
выключен, сборка выполняется, а публикация пропускается. Workflow также можно
запустить вручную через вкладку Actions.

В настройках репозитория **Settings → Pages → Build and deployment → Source**
должен быть выбран **GitHub Actions**. Для Pages из приватного репозитория нужен
подходящий платный план GitHub; на GitHub Free репозиторий должен быть публичным.

Ожидаемый адрес после успешного деплоя:
<https://andrey-hauryk.github.io/our-capital/>.

При переименовании репозитория обновите `base` в `vite.config.js` и адреса сайта
в этом файле.

Документация: [Vite: GitHub Pages](https://vite.dev/guide/static-deploy.html#github-pages),
[GitHub: custom workflows](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).
